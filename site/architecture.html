AI writing tools today block

With a chat beside the file, you ask, wait, review, then ask again.

E.g. Claude Code desktop, Cursor, Copilot Edits.

Or they queue the agent's turns

When an agent answers comments, its turns run one at a time, in one queue. You keep writing; your second ask waits for the first.

E.g. Claude Docs, as we saw it: comments answered one by one.

In Ponjo, nobody waits

You keep writing while agents work. Each @mention starts its own turn, and turns run at once. Each turn lands as one change you can review and undo.

When it ends, click a turn's edit count to see its change; Undo takes back that turn alone.

The agent acts as a member, on its own copy

Its tools are a member's actions. The model only proposes: the program checks each proposal and applies it to the turn's copy. Below, a real turn of the Ponjo agent's loop, its model scripted.

The tools are the permissions: no shell, and no network but the model's. Text in a doc can at worst make a proposal you undo.

The copy lands on the doc as it is now

When the turn ends, the doc host merges its copy into the doc by line. Where a person changed the same lines meanwhile, the turn runs once more on the new text.

The runner is a reconciler over stateless turns

The running turns always equal the open asks in the comments. A turn keeps no state and changes nothing before its proposal, so turns run side by side, resolving a thread stops its turn at once, and a turn cut off by a restart simply runs again.
